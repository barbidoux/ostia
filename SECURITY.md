# Security policy

Ostia is a media kiosk that scans untrusted removable media. Vulnerabilities in it can let hostile
media reach a protected network, so please report them privately.

## Reporting a vulnerability

Email **matthias.vaytet@gmail.com** with:
- the affected version or commit;
- a description of the issue and its impact;
- steps to reproduce, ideally with a harmless proof of concept (no live malware: use EICAR or a marker).

Do not open a public issue for a vulnerability. You will receive an acknowledgement within 7 days.
We agree on a disclosure date together once a fix is available.

## Supported versions

Ostia is pre-alpha: only the `main` branch receives fixes.
