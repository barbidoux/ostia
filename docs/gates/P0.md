**Surprises.**
- The WSL kernel has no exFAT or NTFS modules: those images mount through FUSE drivers (Q-15).
- CI-only failures that local runs did not show: offline `cargo metadata` needed `--filter-platform host`, and
  `uv` offline installs needed `uv sync --frozen`.
- Dependabot changed the owner-managed `rails.yml`; it is now excluded.
- WP-0.12 grew past its M size: the lock review found fail-open gaps in the contracts (a scan ending CLEAN after
  expiry or with no engine, symbolic links, unsafe output paths) that had to be closed before freezing them.
- PR #15 was merged without the lock steps (item 9).
- `just coverage` measures the wrong Python code (item 3).

**Plan adjustments proposed.**
- Split each lock package in two pull requests: contracts first (reviewed, merged), then the tests and the lock.
  Size lock packages L, or treat contracts as their own S package.
- Make the lock steps part of the lock pull request's checklist, so a merge without `LOCK.sha256` is visible
  (CI could fail on an unlocked directory of the next phase once its lock package is ticked).
- Fix `just coverage` to measure `workers-py/common` and print the Rust summary; decide the coverage scope (item 3).
- WP-1.3 needs `read_only` and `symlink` support in the generator (from the lock review).
- Teach the matrix the gate reports (Q-17) before the P1 gate.
